## 一、时间单位

所有时间衰减公式的时间单位统一为 **天**。

| 符号 | 含义 | 取值依据 |
|---|---|---|
| `Δ_day` | 一天的秒数 | `86400 s`，用于把秒级 timestamp 转为天 |
| `T_now` | 参照时间戳 | 边权衰减：该数据集训练集的最大 timestamp；交互年龄：同上 |
| `Δt_k` | 候选历史交互 k 距 T_now 的时间差 | `Δt_k = (T_now − t_k) / Δ_day`，单位天 |

## 二、边权（图模型用）

对应 `docs/预处理口径冻结.md` 口径 5。

| 符号 | 含义 | 默认取值依据 | 代码位置 |
|---|---|---|---|
| `w(u, i)` | 用户 u 对物品 i 的边权 | 见下式 | `data/prepare_data.py` |
| `λ` | **图边权**时间衰减率 | **`λ₀`**（见第三节），默认由 `results/profile/IS.json` 的 `lambda0.value` 给出；S3-a 调参时按 `λ ∈ {0.25, 0.5, 1, 2, 4} × λ₀` 扫描 | `docs/plan/任务卡.md` 第 441、469、614 行 |
| `α_r` | 反馈强度（行为折算系数） | 按 `docs/预处理口径冻结.md` 表 4-1（buy=3.0, collect=1.5, click=1.0, show=0.1） | `data/prepare_data.py` |

边权公式：

$$
w(u,i) = \alpha_r \cdot \exp\!\left(-\lambda \cdot \frac{T_{\text{now}} - t_{ui}}{\Delta_{\text{day}}}\right)
$$

多行为同一 `(user, item)` 对时，先逐行算 `w` 再求和。

## 三、先验取值 γ₀ 与 λ₀（数据驱动初始化）

对应 `docs/plan/cards/S0-b.md` 与 `scripts/profile_data.py`。

| 符号 | 公式 | 语义 | 来源 |
|---|---|---|---|
| `Δ̄` | `median(相邻交互间隔)` | 同一用户按时间排序后相邻两条训练交互的间隔，单位天 | `results/profile/IS.json` → `inter_gap_days.median` |
| `Ā` | `median(训练集交互年龄)` | 以训练集 `T_now` 为参照，每条训练交互的年龄，单位天 | `results/profile/IS.json` → `interaction_age_days.median` |
| **`γ₀`** | `ln2 / Δ̄` | **注意力时间衰减率的先验**：使注意力权重在 Δ̄ 天后衰减一半 | `results/profile/IS.json` → `gamma0.value` |
| **`λ₀`** | `ln2 / Ā` | **边权时间衰减率的先验**：使边权重在 Ā 天后衰减一半 | `results/profile/IS.json` → `lambda0.value` |

**为什么取 ln2 / 中位数**：使"半衰期 = 中位数"是最自然的数据驱动先验，不依赖人工拍数。论文第 4 章以此替代 V8 的 γ=0.3、λ=0.001 经验值。

IS 实测值（2026-11-17 S0-b）：`γ₀ = 0.0313 /天`，`λ₀ = 0.000456 /天`。

## 四、模型层符号

| 符号 | 含义 | 使用位置 |
|---|---|---|
| `γ` | **注意力时间衰减率** | `rank/models/temporal_din.py`；初始化取 `γ₀`，可 `softplus` 参数化为可学习 |
| `η` | 蒸馏损失权重 | `rank/losses.py`；蒸馏项系数，敏感性 `η ∈ {0, 0.1, 0.3, 0.5, 1.0}` |
| `τ` | 蒸馏温度 | `rank/losses.py`；敏感性 `τ ∈ {1, 2, 4}` |
| `κ` | 蒸馏置信度加权指数 | `rank/losses.py`；`ω = \|2p_T − 1\|^κ`，`κ = 0` 时不加权，敏感性 `κ ∈ {0, 1}` |
| `ρ` | 语义重排权重 | `rank/models/ti_lightgcn.py`；长尾正则与语义重排的权衡 |
| `μ` | 长尾正则强度 | `rank/models/ti_lightgcn.py`；敏感性 `μ ∈ {0, 1e-3, 1e-2, 1e-1}` |
| `λ₂` | L2 正则系数 | 各模型的权重衰减，默认 `1e-4`（S2-a 小网格选定） |
| `d` | 嵌入维度 | 敏感性 `d ∈ {32, 64, 128}` |
| `L` | GNN 层数 | 敏感性 `L ∈ {1, 2, 3, 4}` |
| `N` | 短期注意力通道长度 | `rank/models/temporal_din.py`；敏感性 `N ∈ {5, 10, 20}` |
| `K` | 截断排名（用于 Recall@K / NDCG@K） | 论文实验固定 `K ∈ {10, 20}` |
| `a_k` | 第 k 个历史交互的注意力权重 | `temporal_din.py`；未加时间衰减前的原始注意力 |
| `ã_k` | 经时间衰减修正后的注意力权重 | `temporal_din.py`；`ã_k = softmax_k(a(e_k, e_c) − γ · g(Δt_k))` |

注意力公式：

$$
\tilde{a}_k = \text{softmax}_k\!\left(a(e_k, e_c) - \gamma \cdot g(\Delta t_k)\right)
$$

其中 $g$ 支持 `linear(Δt/Δ_day)` 与 `log(ln(1 + Δt/Δ_day))` 两种形式（敏感性见 S3-a）。

## 五、蒸馏损失

$$
\mathcal{L} = (1-\eta)\cdot \text{BCE}(y, \sigma(\ell_S))
        + \eta\cdot \tau^2\cdot \omega \cdot \text{BCE}(\sigma(\ell_T/\tau), \sigma(\ell_S/\tau))
$$

其中 $\ell_T$ 为教师 logits、$\ell_S$ 为学生 logits、$\omega = |2p_T - 1|^\kappa$ 为置信度加权、$\sigma$ 为 sigmoid。

## 六、评估指标

| 符号 | 含义 | 备注 |
|---|---|---|
| `Recall@K` | LOO 下等于 `Hit Rate@K`（测试正样本在 Top-K 内） | `docs/plan/cards/S1-a.md` |
| `NDCG@K` | IDCG=1（每用户 1 个正样本） | 同上 |
| `HR@K` | 等于 Recall@K | 同上 |
| `AUC` | 教师模型区分正负样本的能力 | `docs/plan/cards/S3-c.md` |
| `GAUC` | 按用户加权的 AUC | 同上 |
| `ECE` | 校准误差（可靠性） | 同上 |
| `Fleiss κ` | 多标注者一致性 | `docs/plan/cards/T-f.md` |
