# T-case 真实用户案例分析（4.5.8）

- 周次：W4（12/15 – 12/18）
- 线：写作线
- 估时：0.5 天
- 依赖：S-rank-distill（需要完整模型输出）

## 资源需求

| 类型 | 说明 |
|-----|------|
| **GPU** | ❌ 不需要（推理用已训练模型） |
| **SSH** | 可选 |
| **时长** | ≈ 2 小时 |

## 目标

整改意见要求用 IS 真实用户替换论文 4.5.8 节中的虚构案例，并补充注意力热力图（图 4-8）。

## 实现

### 案例选取

从 IS 测试集中按用户 ID 选取三类典型用户（需有真实交互记录）：

| 案例 | 选取条件 | 验证要点 |
|------|---------|---------|
| 案例一：重度活跃用户 | 训练集交互 ≥20 条 | TI-LightGCN 对专业偏好的精准捕捉 |
| 案例二：冷启动用户 | 训练集交互 3-5 条 | User Memory 对冷启动的补偿效果 |
| 案例三：兴趣转移用户 | 近期行为与历史行为品类差异大 | 时间偏置注意力对短期兴趣的感知 |

### 流程

1. 用 S-recall-main 产出的 TI-LightGCN + S-rank-distill 产出的 Temporal-DIN+蒸馏模型
2. 对每个案例用户跑推理，记录 Top-5 推荐结果
3. 同时跑 LightGCN+DIN 基线作为对照
4. 提取 Temporal-DIN 的时间偏置注意力权重，生成热力图（图 4-8）
5. 用真实交互数据替换论文中的虚构品牌型号与评分

### 注意事项

- 论文中原有的品牌型号（西门子、倍福等）、"注册行业标签"、专家评分 4.8/5 均为虚构，须全部替换为真实数据
- Amazon IS 不含用户注册行业信息，不可在正文中提及
- γ 数值须与复核后定值一致（非原文的 0.3/天）
