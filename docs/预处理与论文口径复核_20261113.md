## 三、逐条证据与修复建议

### A1 🔴 边权重与三元组含 test/val，训练即泄漏

**证据**（IS）：

```
edges.csv 412,947 = train 310,977 + val 50,985 + test 50,985
triples 正样本 355,285 = train 270,019 + val 43,119 + test 42,147
                       → 24.0% 的正样本来自 test/val
test 的 50,985 个对中，42,147 个（82.7%）同时是训练三元组的正样本
```

TH / OP / AJ 同样存在，test 对中作为正样本进训练的比例分别为 78.4% / 83.0% / 43.0%。

**根因**：`process_dataset` 在 `temporal_split` **之后**才调 `compute_edge_weights(df)` 与
`build_bpr_triples(df)`，两者都吃全量 `df`。论文 4.1.5 段264、4.1.6 段271 也明确写
「从数据集加载**全量**交互记录」，口径与论文本身也冲突。

**影响**：Recall@10 会被系统性抬高（模型在训练时已把测试答案当正样本传播），
这属于审稿人一看划分代码就能认定的严重问题；且一旦模型跑起来，表5-4/5-5/5-9 全部要重跑。

**建议修复**（改动很小）：

```python
# process_dataset 内，第 6、7 步改为只用 train
train_df = splits["train"]
edges = compute_edge_weights(train_df, lam=args.decay_lambda)
triples = build_bpr_triples(train_df, ...)
```

同时把 4.1.5 段264 的「全量交互记录」改为「训练集交互记录」，4.1.6 段271 同改，
并在 5.1.1 补一句「图构建仅使用训练集对，test/val 不参与」。
预期 `edges.csv` 条数：IS 310,977。

### A2 🟠 硬负样本「50%」与实测 12%

**证据**：`build_bpr_triples` 的 `pick_hard` 会被 `hi > lo` 与后续
`neg != pos` 双重削减；且只有 **27.9%（14,219/50,985）** 的 IS 用户在训练集中有 rating≤2 的物品。

| 数据集 | 三元组 | 实际硬负 | 占比 |
|---|---|---|---|
| IS | 1,421,140 | 176,620 | **12.4%** |
| TH | 26,300,804 | 4,846,580 | **18.4%** |
| OP | 6,218,284 | 773,742 | **12.4%** |

**建议（二选一，推荐前者）**：

1. 改论文：4.1.2 段247 的「含 50% 硬负样本」→「硬负样本占比约 12%（仅 27.9% 的用户存在
   评分≤2 的历史物品，无硬负池时退化为均匀负采样）」。一句话即可消除复现性缺口。
2. 改代码：对无硬负池的用户也保证 50%（不可能，池为空），或提高 `hard_ratio` 到 0.9
   使实际占比逼近 50%——但这会让有硬负池的用户被硬负淹没，需先做对比实验。

### A3 🟡 两处可直接核出的小数字

- 5.1.1 段407：「稀疏度均高于 99.97%」——IS 实测 **99.9687%**，低于 99.97。
  改为「稀疏度均不低于 99.96%」，或逐项列举。
- 4.1.1 段229 写「22.2 年」，5.8.1 段498 写「22.1 年」。实测
  (1692994801 − 994249707)/86400/365.25 = **22.14 年** → 统一写 22.1。

### A4 🟡 表5-11 标签未同步

V8 的 3.1 修订清单声称已把表5-11 的「移除行为类型权重」改为「移除反馈强度权重」，
但 docx 表格 19 第 3 行仍是**「移除行为类型权重（统一权重=1.0）」**，同表第 5 行
「行为权重+时间衰减均移除」也应一并改为「反馈强度权重+时间衰减均移除」。
4.1、创新点、本章小结均已用「反馈强度」，此处是全文唯一残留。

### A5 🟡 第3章演示规模与表5-1 冲突

段186、段210、段542 三处写「约 16,000 用户、10,000 商品」。表5-1 的 IS 是
50,985 / 25,848。建议统一表述为「线上演示环境按表5-1 的 IS 规模（约 5 万用户、
2.6 万商品）部署」，否则读者会认为系统与实验用的不是同一份数据。

### A6 🟡 λ 符号两义

5.1.2 段413：「L2 正则化系数 λ=1e-4」；4.1.2 式(4-1)：「λ=0.001 为时间衰减率」。
同一章内 λ 两个含义。建议把式(4-6) 的 L2 项与 5.1.2 的系数改记为 λ₂ 或 `wdecay`
（LightGCN 原论文用 λ 表示 L2，如需保留请在 5.1.2 加一句「此处 λ 为 L2 系数，
区别于式(4-1) 的时间衰减率」）。
