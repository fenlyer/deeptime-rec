| 类型 | 说明 |
|-----|------|

| **SSH** | 需要登录 AutoDL 服务器 |

## 目标

扫描 3 个核心超参数，验证鲁棒性。

## 简化策略

只扫描 3 个参数（原文要 5 个），每个参数 3-4 个值：

| 参数 | 候选值 | 默认值 |
|-----|-------|-------|
| λ（时间衰减率） | 0.0001, 0.001, 0.01, 0.1 | 0.001 |
| L（图卷积层数） | 1, 2, 3, 4 | 3 |
| d（嵌入维度） | 32, 64, 128 | 64 |
