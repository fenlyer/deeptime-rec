# eval/ — 统一评估与统计

- **用途**：召回与排序的统一评估入口，含指标计算、全排序、配对检验、分层分析。
- **输入**：模型输出（嵌入或打分）、测试集、屏蔽规则、训练集交互数。
- **产出**：`per_user.parquet`、指标 JSON、配对检验结果、分层指标。

## 模块

| 文件 | 作用 | 口径要点 |
|---|---|---|
| `metrics.py` | Recall@K / NDCG@K | LOO 下 IDCG=1；rank>K 记 0 |
| `full_rank.py` | 全排序 + 屏蔽训练/验证物品 | 并列取悲观排名；支持 `target=all/pos` |
| `paired_test.py` | 两模型多 seed 配对检验 | **样本单位是用户，不是 seed**；先按用户跨 seed 平均 rank，再配对；`d_z = t/√n`（n=用户数） |
| `strata.py` | 冷启动分层（0-4 / 5-9 / 10-29 / ≥30） | 分层只数**训练集**行数；按人数加权守恒校验，容差 1e-9 |

## paired_test 的口径说明

V8 5.5.3 用 t(4)（按 4 个 seed 做检验）是错的：seed 只是对同一用户的重复测量，
不是独立样本。本模块改为逐用户配对，n 为用户数。

差值方差为 0（所有用户差值完全相同）时 t 与 d_z 无定义，JSON 中记 `null`
并置 `degenerate: true`，不写 inf/nan。

## strata 的守恒校验

`Σ(n_i · metric_i) / Σ n_i` 必须等于整体 metric。不等说明有用户没落层，
或者指标不是逐用户可加的。`assert_conservation` 会直接抛错。

`per_user` 中出现但训练集中没有的用户 → 报错停下，不静默丢弃（避免掩盖切分口径不一致）。
