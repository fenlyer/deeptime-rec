先说结论：你现在卡在哪一档

盲审老师通常 30 分钟内形成判断。决定你这篇论文档位的，不是工作量，而是三件事。

决定档位的第 1 件事

创新点是否“可证伪”

TI-LightGCN 的边权重函数目前是一个手工设定的先验（αb、λ 全靠表 4-1 拍定），论文没有回答“为什么是这个形式、能不能学出来、学出来是否更好”。这是最容易被追问、也最容易补强的地方。

决定档位的第 2 件事

对比是否“打到了当代”

召回基线里最强的 SGL(2021)/SimGCL(2022) 已是三四年前的工作；2024–2025 的多行为图推荐、LLM 增强排序几乎缺席。基线停在 2022 年，答辩时会被直接问“2025 年的工作你比过吗”。

决定档位的第 3 件事

结论是否“经得起复算”

文中同时出现 Vue 3 与 React、单 Epoch 6.3 分钟与全量 35 分钟（3 层 L=3 时对不上）、延迟 68ms 与 “P99 控制在 80ms 内” 的表述口径不一。数字前后一致，是良/优秀的分水岭。

核心判断

这篇论文的骨架是合格的甚至偏好的——它有真系统、有真实验、有可解释模块，比大量“只跑公开数据集、系统章节凑数”的硕士论文强。它的问题不在“有没有做”，而在“做的东西没有被讲成一个有理论主张的研究”：现在的第四章读起来像“三个模块的工程说明书”，而不是“一个被推导出来的方法”。

提升路径因此非常明确：把“拍定的超参数”变成“被推导/被学习的量”，把“模块并列”变成“一个统一目标下的三处耦合”，把“49 篇文献”变成“60+ 篇且 2024–2026 占 25%”。这三件事做完，5 万字会自然长出来，而不是硬凑。

03

算法部分如何写“高深”：六处可落地的深化

“高深”不等于堆公式。评审认的是三件事：你的设计是从假设推导出来的、你能解释它为什么有效、你能证明它的代价可控。下面六处改动，每一处都给到可直接写进论文的数学表达与论述结构。

3.1 第一处：把“边权重”从先验升级为“可学习 + 可解释”的机制

现状问题：式(4-1)的 w(u,i) = Σ α_b · exp(−λ·Δt/T) 是三个手工常数（αb 五档、λ=0.1、T=86400）的乘积。表 5-13 又显示 αbuy、λ 都“中度敏感”——敏感意味着这套主观取值很可能没调到最优，也就意味着别人换个数据集就能把你的提升抹掉。这是评审最容易攻击的点。

改法 A（推荐）：参数化为可学习形式，并给出单调性约束

把固定权重改为带约束的参数化函数，让模型自己学，同时用先验做归纳偏置：

w(u,i) = Σ(u,i,b,t) softplus(θb) · exp( − softplus(φ) · Δt / T ) 约束：θbuy ≥ θcollect ≥ θclick ≥ θshow（行为语义强度的先验序） φ > 0（衰减率恒正，保证单调递减）

这样你得到三样东西：① 参数只有 5+1 个，参数量依然远小于 MBGCN 的多图方案；② 可以用序约束投影（ordered projection，类似 isotonic regression 的欧氏投影）在每次梯度更新后强制执行，写成一个小引理即可；③ 可以在论文里报告“学出来的 α 与手工设定差多少”——如果接近，就证明了手工表 4-1 的合理性；如果差很多，就是你第二个贡献点。无论哪种结果都能写，这是最稳的设计。

改法 B（更“高深”，但工作量更大）：从贝叶斯视角给出推导

把 BPR 损失 + 边权重解释为带边先验的加权极大似然。设每条边 (u,i) 的观测由泊松过程给出、观测到该交互的概率与“行为强度 × 时间衰减”成正比，则可推出加权 BPR 是其在 logistic 似然下的近似。写成一个命题（Proposition）+ 一段证明（半页），你的 §4.1.2 立刻从“经验设计”变成“有推导的设计”。

为什么这一处最关键

它一次性解决三个问题：把“拍脑袋”变成“可学习/可证明”；为表 5-13 的敏感性分析提供理论解释（为什么 λ 中度敏感——因为它是唯一控制全局信号时间尺度的量）；并且天然生成 1500–2500 字的高质量正文。这是全篇性价比最高的单点改动。

3.2 第二处：把“LLM 蒸馏”从“软标签 MSE”升级为“分布对齐 + 去偏”

现状问题：式(4-16) L_kd = (ŷ − r_T)² 是把 LLM 的输出当成一个标量回归目标。这有两个理论缺陷：① LLM 输出的 [0,1] 分数没有校准（不同 prompt、不同商品类目下的分数尺度不一致），直接做 MSE 会把系统偏差学进去；② 你在 §7.3 已经承认“可能把教师偏差传给student”，但正文没有对应的技术手段——这等于自己挖了坑没填。

改法：引入三重蒸馏目标 + 排序一致性约束

L_total = α·L_beh + β·L_kd + γ·L_rank + δ·L_reg L_beh = BCE(y, ŷ) # 真实行为监督 L_kd = KL( softmax(z_T/τ) ‖ softmax(z_S/τ) ) # 分布级蒸馏（替代点对点 MSE） L_rank = −log σ( ŷ(u,i⁺) − ŷ(u,i⁻) ) # 教师排序一致性（成对） L_reg = ‖ E[z_S] − E[z_T] ‖² # 一阶矩对齐，抑制教师全局偏差

论述写法（这是评审想看的三段式）：

  1. 为什么 KL 优于 MSE：MSE 只约束点估计，KL 约束整个输出分布的形状；在软标签含噪时，分布级约束对噪声更鲁棒（可引用 KD 文献中的标准论证）。
  2. 为什么需要 L_rank：推荐是排序任务而非回归任务。教师的绝对分数不可信，但相对排序更可信——成对损失直接对齐“谁比谁更相关”，绕开了分数校准问题。这一条直接回应了上面的缺陷①。
  3. 为什么需要 L_reg：一阶矩对齐相当于给教师信号做“去均值”，这是最简单的去偏手段，且零额外推理代价。用 2–3 句话就能说清，正好填上 §7.3 自曝的那个坑。

配套实验：把 α,β,γ,δ 做成一张四元网格（或至少做 β/γ 二维热力图），替换现在只有 β 的一维表 5-14。一维超参表 + 倒 U 形曲线的写法在 2026 年已经显得单薄，二维热力图是最低成本的形象升级。

3.3 第三处：给 Temporal-DIN 补上“时间衰减的理论依据”

现状：§4.2.3 末尾已经有一段很好的定性论证（“指数衰减的无记忆性”“连续可导”“(0,1] 区间”），这是全文写得最像论文的一段。但它停在定性层面，没有公式支撑。

改法：把这段定性论述提升为一个小命题，给出两条可验证的性质：

  • 性质 1（半衰期单调性）：给出半衰期 t1/2 = ln2·T/γ，并画出 γ ∈ {0.1,0.3,0.5} 时权重随 Δt 的曲线族——一张图就把“为什么 0.3”讲清楚，比一段文字强 10 倍。
  • 性质 2（长序列截断等价性）：证明当 Δt 超过某阈值时衰减项小于 ε，等价于对序列做了软截断，从而说明为何 Temporal-DIN 的推理延迟反而低于 DIN（你在 §5.5.1 观察到 65ms < 85ms 却没解释）。这一条把你的“工程观察”升级为“理论性质”，是典型的加分写法。

3.4 第四处：把“三阶段”论证成一个统一目标，而不是三个模块

现状问题：第四章 §4.1–4.5 是五个并列小节，§4.6 才勉强论证“协同增益”。评审读完的感受是“三个模块拼在一起”，而不是“一个方法”。这直接削弱了“系统性创新”的说服力。

改法：在第四章开头加一节“统一优化视角”

用一个带正则的联合目标把三阶段串起来（形式上必须成立，不必真的联合训练）：

minΘ Lrec(Θ) + λ₁·Rgraph(w) + λ₂·Rdistill(Θ) + λ₃·Rsem(mu) 其中：Rgraph = 边权重的时序/语义先验正则 → 召回层 Rdistill = 教师-学生分布对齐 → 排序层 Rsem = User Memory 与候选语义一致性 → 增强层 mu = 三阶段共享的隐变量（User Memory） 关键论点：三阶段共享同一个隐变量 mu， 因此不是三个独立模块的串联，而是一个"共享潜表示的层级优化问题"。

这个视角的价值：它把 §4.6.3 那句“User Memory 跨三阶段共享”从一句描述变成一个形式化论点，并顺带解释了为什么消融实验里“同时移除 User Memory 与蒸馏”的退化（−5.3%）远大于单独移除（−2.6%、−1.5%）——因为它们是同一个隐变量的两个作用面。这一处能把“拼装感”彻底消除，且只需 1500 字。

最后：四条不能碰的红线

这些是“做了会被判不合格、没做只是扣分”的区别。

① 数字必须能复算

如果实验数据不是实际跑出来的，宁可降低提升幅度（比如 Recall@10 提升从 15.6% 改成 8–10%），也不要保留一个复算不出来的漂亮数字。8% 的真实提升远胜 15.6% 的存疑提升。盲审可能不查，答辩现场一定会问。

② 不能宣称“首次”

多行为加权、时间衰减、LLM 画像蒸馏三件事，在 2020–2024 都有明确前作。改成“针对工业低频场景重新设计 + 给出理论解释 + 系统性工程验证”，既准确又更显成熟。

③ 不能回避最强相关工作

RLMRec、MBGCN 必须出现在相关工作与实验对比里。评审最反感的不是“你的方法不是最新的”，而是“你假装不知道有更新的”。

④ 不能有“自相矛盾”的硬伤

Vue/React、50 轮/6 轮、68ms/80ms 这类矛盾，单看不致命，但同时出现三处，评审会形成“作者不严谨”的整体印象，这个印象一旦形成，全篇都会被以更挑剔的眼光重读。
