## 模型设计

### 核心改动（相对 DIN）

1. **时间偏置注意力**：`a_k = softmax(a(h, e_i) - γ × Δt_k / T)`
   - γ 取值需依据图3-3交互间隔分布重新确定（现 γ=0.3/天，与IS中位间隔22.1天相比偏大，需复核）
2. **双通道**：
   - 短期通道：**最近 N 条行为**（N∈{3,5,10}，做敏感性分析）
   - 长期通道：User Memory 向量（256 维 or 384 维→投影）
3. **门控融合**：`h = g ⊙ h_short + (1-g) ⊙ h_long`

### 实现文件

- `rank/models/temporal_din.py`：模型定义
- `rank/layers.py`：时间注意力层、门控层

## γ 定值流程

1. 依据 S0-b 的图3-3 交互间隔分布确定 γ
2. 现 γ=0.3/天意味着相隔10天权重差 e^(-3)≈0.05，可能过大
3. 若复核后需改为 γ=0.03（半衰期23天），需重跑全部实验
4. 在 S-rank-main 之前完成 γ 定值
